# 방풍림 전투 FPS — 2단계: 적 AI와 교전

브라우저에서 돌아가는 1인칭 보병 전투 게임. 1단계는 평원 농경지의 방풍림 지대에서
**조준하고, 쏘고, 맞았다는 걸 확인하는 순간**을 실제 탄도·실제 수치로 만들었다.
2단계는 **보고 들은 만큼만 아는 적이, 같은 탄도·흔들림·은폐 규칙으로 쏘고, 분대로 움직이는 교전**을 더한다.
적 AI는 플레이어의 실제 좌표를 읽지 않는다. 크로스헤어·체력바·적 표식·히트마커·탄약 숫자·히트스캔은 없다.

- Three.js(r186) + Vite, JavaScript ES 모듈
- 외부 3D 모델·텍스처·사운드 파일 없음: 지형·나무·인물은 절차적 지오메트리, 소리는 Web Audio 합성
- 무기·탄약·재질·이동·지면·나무·인체·시나리오 수치는 전부 `src/data/`

## 실행

```bash
npm install
npm run dev              # http://localhost:5173 → "클릭해서 시작"
npm run test:ballistics  # 100~600 m 사거리표 출력 + 공개 자료 대비 검증(오차 10% 이내면 통과)
npm run test:accuracy    # 자세 × 거리 명중률 표(완벽한 판단 + 사람 흔들림·탄 분산만) + 목표 범위 + 적 사수가 같은 모델인지
npm run test:perception  # 경계 중인 적이 조건별로 플레이어를 알아채기·알아보기까지 걸리는 시간 + 사격 횟수별 위치 오차
npm run test:consistency # 화면(GPU)과 판정(CPU)의 지형·풀 덮개 높이 비교(Playwright 필요)
npm run build            # 정적 빌드(dist/)
npm run shots            # 고정 시점 7곳 스크린샷 + 그리기 호출·삼각형·CPU 갱신 시간 → shots/current/
npm run shots -- before  # 이름을 붙여 저장(shots/before/) — 변경 전후 비교용
```

`npm run shots`는 Playwright(Chromium)로 같은 시점·같은 바람·같은 시각을 찍는다(숲띠 가장자리·들판 건너 숲띠·덤불 근접·숲띠 내부·숲띠 끝 + 흙둔덕·쓰러진 나무, `SHOTS_ONLY=2-field,6-berm`처럼 일부만). 처음 한 번 `npx playwright install chromium`.
GPU가 없는 환경에서는 소프트웨어 렌더러(SwiftShader)로 찍으므로 프레임 시간은 의미가 없고 그리기 호출·삼각형 수만 참고한다(`SHOTS_GPU=1`이면 GPU 사용 시도).

포인터 잠금이 필요하다(화면 클릭). Esc를 누르면 일시정지·설정 화면이 열린다. 헤드폰 권장.
적 배치는 시작할 때마다(그리고 P를 누를 때마다) 다르다. 같은 배치를 다시 보려면 주소에 `?seed=1234`를 붙인다(디버그 모드 F8 화면에 현재 시드가 나온다).

## 2단계: 적 AI와 교전

### 시나리오와 끝 (`src/data/scenario.js`, `src/enemies/EnemyManager.js`)
- 플레이어는 남쪽 숲띠 북쪽 가장자리에서 북쪽을 본다. 북쪽 맞은편 숲띠(300~400 m)에 1분대(분대장 + 4명 사격조 2개 = 9명), 동쪽 연결 숲띠(50~200 m)에 3사격조(4명). 모두 7.62×39 mm 소총.
- 처음에는 아무도 플레이어를 모른다. 경계(45 %, 숲 가장자리에서 무릎·서서 관측)·순찰(25 %)·휴식(30 %, 숲 안에서 무릎 꿇고 쉼 — 반응이 1.5배 느림) 중이고, 시작 자리는 그럴듯한 후보 중에서 시드로 뽑는다(매번 다름).
- 모든 적이 무력화·철수하거나 플레이어가 쓰러지면 끝. 결과 화면: 교전 시간, 발사·명중 수, 무력화·철수한 적, 플레이어 상태(다치지 않음 / 부상 부위 / 전투 불능 / 사망), 쓰러졌으면 디브리핑. P로 다시 시작.

### 적 인지 (`src/ai/Senses.js`, `Sight.js`, `Knowledge.js`, `src/data/perception.js`)
- **보기**: 가시도 = 겉보기 노출 면적(내 몸 5부위의 시선 투과율 가중 — 잎 볼륨 Beer–Lambert, 그루터기·잡초·해바라기 덮개, 줄기·통나무·지면은 막음) × 배경 대비(들판 1 / 숲 0.6 / 하늘 4) × 조명(그늘 0.28~0.55) × 움직임(정지 1 ~ 질주 5.7) × 연무. 시야 중심 ±10°는 잘 보고 주변은 (10°/θ)²로 떨어지되 움직임은 주변에서도 보인다. 고개를 돌려 훑어본다.
- **탐지는 시간에 걸쳐 쌓인다**: 모름 → 의심(뭔가 움직였다: 방향만 대강) → 수색(위협은 있는데 위치를 모름) → 위치 파악(오차 50 m 이하) → 교전(지금 보이거나 그쪽으로 쏘는 중).
- **듣기**: 총구 폭음 '쾅'으로 방향 ±22°(숲 안은 잔향으로 더 나쁨), '딱'(초음속 탄이 30 m 안을 지남)을 먼저 들으면 방향이 그쪽으로 끌리고 더 헷갈린다. 딱-쾅 시간차로 거리 ±30 %, 소리 크기만이면 ±50 %. 같은 자리에서 거듭 쏘면 추정이 좁혀지고(방위 하한 8°/12°), 쏘고 옮기면 적은 한동안 옛 위치를 향한다. 발소리·덤불 소리(지면별 12~26 m)와 탄창·노리쇠 소리(6~20 m)는 가까이서만, 바람이 세면 덜 들린다.
- 추정은 관측자 기준 (방위, 로그 거리) 칼만으로 합치고, 합친 방위를 따라 숲띠 긴 변에 맞춘다('저 숲 가장자리에서 쐈다' — 오차 타원은 가장자리를 따라 길게). 실제 위치가 적이 아는 2σ 오차 안에 드는지를 `AILog`로 늘 확인한다.
- **나누기**: 외침(20 m 안 확실, 80 m에서 0, 0.6~1.5 s 지연, 위치 오차 + 4 m + 거리의 10 %) — 플레이어에게도 들린다. 부대 간 무전(3~8 s 지연, 오차 × 1.5 + 15 m). 전해 들은 위치는 자기 것보다 나을 때만 바꾼다.

### 적 사격 (`src/ai/Shooter.js`, `src/data/weapons.js` `rifle762`, `src/data/ammo.js` `762x39_ps`)
- 7.62×39 mm 7.9 g 보통탄, 초속 715 m/s, G7 0.149, 분당 600발, 30발 탄창 × 6, 재장전 3.0 s(탄을 다 쓰면 + 0.6 s, 엎드리면 × 1.35). 약 466 m부터 아음속 — 그보다 멀리 지나는 탄은 '딱'이 없다.
- 정확도는 플레이어와 같은 모델: 같은 사람 흔들림(`AimModel`) × 숙련도(0.8~1.5) × 제압·부상, 총+탄 분산 σ 1.6 MOA, 눈대중 거리(병사마다 ±10~20 %)에 맞춘 앙각, 바람 보정 없음, 움직이는 표적은 비행시간만큼 앞에(속도 추정 ±30 %).
- 첫 발까지 0.5~1.5 s 이상(멀수록 길게), 보이면 조준 단발, 가까우면 짧은 점사. 안 보이면 추정 위치 분포에서 뽑은 점으로 2~5발 제압 점사. 탄창 단위로 탄을 쓰고 숨어서 재장전하며("재장전!" 외침), 예비 탄창이 적으면 제압을 아낀다. 새 정보가 25 s 없으면 사격 중지.

### 적 전술 (`src/ai/Brain.js`, `Squad.js`, `CoverMap.js`, `NavGrid.js`)
- **접촉**: 엎드리거나 가까운 실제 엄폐물(위협 쪽을 막는 줄기·통나무·둔덕·배수로·짚 더미·뿌리판) 뒤로 → 방향 추정 → 응사. 엄폐 뒤에서 최소한만 내다보고 쏘고, 몇 번 쏘면 자리를 옮긴다.
- **분대**: 사격과 기동 — 한 사격조가 제압하고 다른 사격조가 숲띠·배수로를 따라 측면으로 간다(노출 비용을 넣은 A*: 위협에게 보이는 열린 칸은 비싸다). 열린 곳은 짝 교대 약진(3~5 s 달리고 엎드림, 서 있는 짝이 엄호).
- **사상자**: 동료가 엄폐물까지 끌고 간다. 팔다리를 다친 적은 엎드린 채 쏜다.
- **사기**: 사상자·분대장 손실·제압으로 떨어지고 조용하면 회복. 흔들리면 버티기만, 꺾이면 뒤 숲띠로 철수한다.

### 제압 (양쪽 같은 표, `EnemyManager.SUPPRESSION`)
- 1~3 m 안을 스치는 탄·근처 탄착이 제압을 올리고 약 6 s에 걸쳐 풀린다.
- 적: 엄폐에 붙고, 쏘면 부정확하고(흔들림 × (1 + 1.6 × 제압)), 움직이려 하지 않는다.
- 플레이어: 짧은 움찔(카메라·총 작은 튐), 심박 상승 → 흔들림 증가, 숨소리 거칠어짐, 시야 가장자리가 살짝 좁아짐. 크게 흔들거나 흐리게 하지 않는다.

### 소리: 딱과 쾅 (`src/audio`)
- '딱'은 탄 경로 위 마하 원뿔 방출점에서, 충격파가 닿는 시각에 난다 — 사수 방향이 아니다. 가까이 스칠수록·빠를수록 크고 날카롭고, 음속에 가까운 먼 탄은 약하고 둔하다. 아음속 탄은 가까이서 '휙'.
- '쾅'은 사수 방향에서 거리 ÷ 343 s 뒤. 숲띠를 지나면 작고 둔해지고, 바람 아래쪽으로 잘 들리고, 숲띠 가장자리에서 메아리가 돌아온다. 위치 있는 소리는 HRTF로 앞뒤·위아래가 갈린다.
- 탄착음(흙·나무·잎), 적의 외침·탄창 교환·노리쇠 소리, 다쳤을 때 심장 박동.

### 플레이어 몸과 부상 (`src/player/PlayerBody.js`, `PlayerHealth.js`)
- 적과 같은 골격·히트박스를 카메라 자세(서기·무릎·엎드림·기울이기)에 맞춰 둔다(화면에는 안 그림). 적에게 보이는 정도와 피격 판정에 같이 쓴다.
- 머리·목·흉부 중앙·척추: 즉사. 폐: 3~10 s 안에 시야가 어두워지며 쓰러짐. 복부·골반: 엎드려 기며 쏠 수 있지만 1~3분 뒤 전투 불능. 다리: 엎드려 기기·사격만. 팔: 흔들림 3배·재장전 2.5배. 팔다리 출혈은 지혈대(H)로 멈춘다.
- 피 튀김·붉은 화면 없음: 시야 어두워짐·채도 감소·심장 박동·움직임 제한으로만 드러난다.
- **디브리핑**: 누가(어느 적), 어느 방향·거리에서, 나를 보고 조준했는지(보인 몸 비율) 추정 위치로 제압 사격했는지(그 오차), 내 위치를 안 지 몇 초였는지, 맞을 때 내 자세·움직임, 같은 자리에서 몇 발 쐈는지.

### 디버그
- 디버그 모드(`)를 켜야 아래 키가 동작한다. 끄면 표시와 무적이 모두 꺼진다. 소환한 적·더미는 P(초기화)로 사라진다.
- F2: 적 위치 표식과 이름표(가려져도 보임). F3: 조준점에 적 소환(소환조 부대 — 다른 적과 같은 규칙). F4: 조준점에 더미(움직이지 않는 표적 — 교전 종료 집계와 적 AI에서 빠지고, 맞으면 같은 부상 모델로 쓰러지며 명중 로그에 남는다).
- F8: 적마다 인지 단계·추정 위치와 오차 원(단계별 색)·제압·사기·현재 행동, 부대 상태와 시드, 인지 계산 시간, 'AI가 아는 위치 vs 실제 위치' 요약(출처별 실제 오차·아는 오차·2σ 안 비율·수상하게 정확한 비율). 전체 기록은 콘솔 `__game.enemies.senses.log.dump()`.
- F9: 적 시선(초록 보임·노랑 낌새·빨강 가려짐), 내 가시도, 적 탄 궤적, 소리 사건.
- F6: 디버그 무적(기본 꺼짐).

### 성능
- 시각 평가는 프레임당 4명씩 돌아가며(보이는 적 0.12 s, 가까운 적 0.18 s, 먼 적 0.3~0.6 s마다), 길 찾기는 프레임당 4000 노드씩 나눠 계산한다.
- 측정(이 개발 환경은 GPU가 없어 CPU 갱신만): 적 16명 교전 중 적 갱신(인지·두뇌·길 찾기·몸) 평균 0.4~0.7 ms, 95 % 구간 1.6 ms 이하, 인지만 평균 0.15~0.27 ms. 게임 전체 CPU 갱신 평균 0.8~2.5 ms(95 % 4.6 ms 이하). 렌더링은 1단계와 같은 규모(적 모델 13~16개).

## 1단계: 전장과 사격

### 전장 (`src/world`, `src/render`, `src/data/world.js`, `src/data/trees.js`)
- 1.2 km × 1.2 km 플레이 구역, 1.4 km 높이맵(1 m 격자). 바깥은 해석적 지형(지평선 쪽 완만한 언덕)과 원경이 지평선까지 이어지고, 대기 원근(안개)으로 흐려진다. 지도 끝이 보이지 않는다.
- 지형: 격자 높이를 3차 B-스플라인으로 매끈하게(각진 면 없음) + 지면 종류별 미세 요철(일반 ±2.4 cm, 숲 바닥 ±5 cm, 갈아엎은 이랑 ±6 cm). **CPU 판정(탄착·이동·시야)과 GPU 렌더가 같은 식·같은 반정밀도 값**을 쓴다. 곡면 배수로·둑, 흙둔덕 7곳, 바퀴 자국 흙길 3개(자국 깊이 11 cm, 가운데 풀 둔덕, 마른 웅덩이 자리). 경사면은 풀이 벗겨져 흙이 드러난다.
- 밭: 밀 그루터기(수확 줄 17 cm 간격·높이 10~20 cm, 콤바인 짚 줄 7.6 m마다, 방제기 바퀴 자국 24 m마다, 밭 끝 회전 구역), 갈아엎은 흙밭(이랑 75 cm, 흙덩이, 습해 어두운 낮은 곳), 휴경지(무릎~허리 잡초), 거두지 않은 마른 해바라기 밭(높이 1.7~2.0 m, 줄 0.7 m × 포기 0.35 m — 은폐 덮개로 판정), 원형 짚 더미(짚 관통 재질). 지면 재질 경계는 노이즈로 섞인다.
- 방풍림: 동서 띠 3줄 + 남북 연결 띠 1줄, 폭 16~24 m, 열 간격 약 3.2 m(심을 때의 오차·굽이·빈자리 포함), 열 사이 자생목·어린나무·맹아.
  - 수종(수십 년 묵은 관리 안 된 평원 방풍림): 포플러 19~25 m(좁고 높은 기둥형), 아까시 13~18 m(성기고 불규칙, 두 갈래 줄기), 시베리아느릅 10~15 m(빽빽한 둥근 수관), 네군도단풍 7~11 m·푸른물푸레 11~16 m(하층·중층). 띠마다 구성 비율이 다르다.
  - 고사목(잎 없는 회색, 꼭대기가 부러짐)·꼭대기 부러진 산 나무·크게 기운 나무(10~22°)·쓰러진 나무(뿌리째 뽑혀 흙 뿌리판이 선 것 포함)·그루터기(톱 자른 면/꺾인 면)·숲 바닥의 떨어진 가지와 썩은 가지.
  - 가장자리 단면: 숲 → 관목대(딱총나무·들장미·가시자두·보리수, 같은 종끼리 무리) → 키 큰 잡초 띠(쑥·엉겅퀴·우엉·큰 볏과) → 밭. 띠 끝은 18~32 m에 걸쳐 어린나무·관목으로 낮아진다(수직 벽 없음).
  - 9월 말 오후(북위 48°, 태양 고도 25.5°, 방위 235°): 잎 대부분 녹색, 일부 나무(수종마다 10~35 %)만 수관 위·바깥부터 노랗게 물듦, 마른 잎 몇 장.
- 판정: 공간 해시(4 m 격자)에 줄기(휘고 기운 줄기 = 화면과 같은 식)·굵은 가지·죽은 가지 그루터기·통나무 마디·뿌리판·짚 더미·잎 볼륨(수관·덤불 타원체)을 등록. 땅 위 2.3 m 아래를 지나는 탄은 그루터기·잡초·해바라기 덮개(GroundCover — 화면 풀 높이와 같은 식)를 통과한다.

### 렌더링 (`src/render`)
- 색: 선형 HDR(MSAA 4×) → 노출 → AgX 톤매핑 → 약한 색보정(sRGB 출력). 아주 약한 블룸, 해를 볼 때 나무 사이 빛줄기, 가벼운 SSAO(반 해상도).
- 하늘: 해석적 산란 모델(Rayleigh·Mie) + 태양 원반 + 적운·권운(바람 따라 흐르고 땅에 같은 모양의 구름 그림자). 하늘빛은 SH(구면조화)로 모든 표면에 같은 규약으로 들어간다. 대기 원근: 300 m 숲띠는 살짝 푸르게 흐리고 1 km 밖은 옅은 실루엣.
- 그림자: 2단 캐스케이드(가까운 곳 선명, 원거리까지), PCF 부드러운 가장자리. '높음'은 잎도 그림자 맵에 그린다. 그림자 범위 밖·잎 그림자 없는 품질은 수관 밀도 지도로 숲 안을 어둡게(400 m 밖 숲 안·그 안의 적도 어둡다).
- 지형: 카메라 중심 기하 클립맵(10단계, 0.25 m~), 절차 생성 지면 질감 배열(그루터기·흙·낙엽·짚·이끼·진흙·길) + 법선.
- 나무: 수종 템플릿 23개(가지 골격: 휘고 갈라지고 가늘어짐, 아래쪽 죽은 가지) + 잎 뭉치 카드(실제 잎 크기로 그린 잔가지 다발, 구형 수관 법선, 양면 + 투과광, 나무·가지마다 색 차이, 3단 바람 흔들림) + 수종별 껍질 질감·법선(포플러 위 흰 껍질과 검은 피목, 아래 거친 회갈색; 아까시 깊은 세로 골; 느릅 그물 무늬). LOD: 가까이 전체 → 중간 단순화 → 멀리 8방위 임포스터, 화면 디더로 전환.
- 풀·잡초·그루터기·해바라기: 절차 생성 식물 아틀라스 16종을 교차 카드로(바람에 휨, 마름 정도 포기마다 다름), 높이는 판정 덮개와 같은 식. 먼 곳은 개수를 줄이고 지면 색으로 이어진다.
- 원경: 지도 밖 방풍림 격자(가까운 나무와 같은 임포스터를 줄지어 합성), 마을(집·창고·나무)·곡물 엘리베이터, 고압 송전선(격자 철탑·늘어진 전선), 나무 전신주.
- 분위기: 수관 아래 떨어지는 잎, 바람에 떠다니는 엉겅퀴 갓털·먼지(역광에서 반짝임).
- 품질 프리셋 낮음/중간/높음: 그림자 해상도·거리, 잎 그림자, 블룸·빛줄기·SSAO, 풀 거리·밀도, 나무 LOD 거리.

### 바람 (`src/world/Wind.js`, `src/render/shaderLib.js`)
- 전역 바람: 방향 + 기본 풍속(시작 시 2~8 m/s 랜덤 또는 고정) + 바람을 따라 흘러가는 돌풍 패치 + 풍향 흔들림(±13°).
- 높이 분포: 로그 법칙(z₀ = 0.05 m, 기준 2 m). 엎드린 높이(0.3 m)는 2 m 높이의 약 절반.
- **방풍림 차폐**: 띠 안 0.3~0.8, 풍하측 3~6H에서 최저 약 0.3 → 10H 0.56 → 20H 0.88 → 30H 회복, 풍상측은 2H 이내만 약간 감소. 비스듬한 바람은 cos로 약화, 띠 끝·틈으로 돌아온 바람은 차폐 없음(틈에서는 약간 빨라짐). 차폐는 0.7H~1.5H 위로 사라짐.
- 같은 식(같은 해시 노이즈)을 CPU(총알)와 GPU(풀·잎·나무 꼭대기 흔들림)가 공유 → 화면의 풀 물결이 실제 탄도에 쓰이는 바람이다. 화면에 풍향·풍속 표시는 없다.
- 소리 전달 훅: 바람 방향에 따라 풍하측으로 소리가 더 잘 퍼짐(`AudioEngine.propagate`).

### 플레이어 (`src/player/Player.js`, `src/data/movement.js`)
- 눈높이 1.65 / 1.1 / 0.3 m, 전환 시간(서기→엎드림 1.0 s, 엎드림→서기 1.45 s 등).
- 속도: 걷기 1.5, 뛰기 3.5, 전력질주 6.0(스태미나 13 s), 앉아 이동 1.0, 포복 0.4 m/s. 지면 배수(흙밭 0.7, 휴경지 0.8 …)와 덤불 속 0.45 배.
- 질주 중에는 총을 내려 사격 불가, 멈추면 0.42 s 걸려 올라옴. 심박 72→최대 178 bpm, 회복 시정수 38 s. 호흡 주기 4 s(지치면 1.6 s).
- 나무 줄기·통나무 충돌. 엎드리면 몸 회전 속도와 조준 상하 범위 제한.
- **총이 길다**: 개머리판~소염기 선분이 줄기·통나무·지면에 닿으면 총을 뒤로 당기고(최대 13 cm), 남으면 장애물 반대쪽으로 비튼다. 많이 걸리면 조준 불가, 탄은 실제로 비틀린 총구 방향으로 나간다.

### 무기 (`src/weapon`, `src/data/weapons.js`, `src/data/ammo.js`)
- 5.56 mm 카빈(14.5 in 총열, 1:7 우선회), 62 gr 보통탄 초속 905 m/s(탄간 표준편차 9 m/s), 분당 750발, 단발/연발.
- 30발 탄창 + 약실 1발, 휴대 탄창 7개(삽입 포함, 기본 휴대량 210발) **탄창별 잔탄 추적**. 파우치는 순서 있는 대기열(전술 재장전한 탄창은 뒤로, 빈 탄창은 덤프 파우치).
  - 전술 2.5 s / 급속 1.65 s / 탄 소진 후 급속 2.15 s / 탄 소진 후 전술 2.95 s(노리쇠 전진 단계 추가). 엎드리면 ×1.4, 무릎 ×1.05.
  - 소리(탄창 멈치·분리·파우치·삽입·안착·노리쇠 전진)가 각 단계 시각에 정확히 맞춰 난다.
  - 탄창 확인(T, 1.8 s)은 숫자 대신 "가득/절반 이상/절반 미만/거의 없음".
- 조준기: 철제(조준선 높이 66 mm, 조준선 길이 0.37 m, 가늠쇠 폭 1.83 mm = 0.072 in → 눈에서 4 mrad: 110 m 밖 상체를 다 가림, 가늠자 구멍 1.75 mm / 5.1 mm, 조준하면 먼 풍경이 가볍게 흐림 — 눈이 가늠쇠에 초점) / 고정 4배율 광학(실시야 7°, 아이릴리프 38 mm, 아이박스 6 mm — 조준 직후·자세 전환·이동·반동 때 가장자리 그림자, **BDC 300~800 m 눈금은 게임 탄도로 직접 계산** — 각 눈금 폭은 그 거리 어깨폭 0.48 m라 거리 측정 막대로 쓴다). 영점 기본 100 m(설정 변경 가능, BDC는 100 m 영점 기준으로 새겨짐). 게임 화면에 거리 표시는 없다(디버그 모드에서만).
- 크로스헤어 없음. 탄은 화면 중앙이 아니라 실제 총구 위치에서 총열 방향(조준선 + 영점 앙각 1.33 mrad)으로 나간다. 조준선-총열 높이차 때문에 근거리에선 조준점보다 아래에 맞는다. 비조준 시는 견착 자세 총열이 약 25 m에서 시선과 교차.
- 반동: 자유 반동 충격량 J = m·v₀ + m_장약·1.75v₀ ≈ 6.5 N·s → 지렛대·관성(자세별)으로 총구 각속도 → 감쇠 스프링으로 자연조준점 복귀 + 수평 무작위. 사수가 되돌리지 못하는 몫은 시선에 누적(발당 서서 약 2.7 / 무릎 1.3 / 엎드려 0.3 mrad — 연발 시 총구가 계속 올라감). 카메라 흔들림·총 모델 후퇴는 탄도와 분리.
- 흔들림(실제 수준, `src/weapon/AimModel.js`): 느리게 떠도는 자세 표류(90 % 지름 엎드려 거치 1.8 / 엎드려 3.8 / 무릎 7.1 / 서서 15 MOA) + 호흡(날숨 끝 자연 정지) + 맥박 튐 + 떨림 + 걸음.
  - 질주 직후 약 2배(심박 따라 수십 초에 걸쳐 회복), 거치 없이 10 s 넘게 서서·무릎 조준하면 팔 피로로 점점 커짐(조준을 풀면 회복).
  - 숨 참기(조준 중 Shift): 호흡 움직임만 멈춘다(표류는 그대로). 5 s 안정, 이후 떨림 증가, 11 s에 강제로 내쉼. 숨이 차면 짧게만 참는다.
  - 거치(통나무·둔덕·배수로 둑·짚 더미·줄기 옆): 흔들림 절반 안팎, 팔 피로 없음.
  - 급한 격발: 단발로 이전 발 뒤 0.45 s 안에 서둘러 당기면 격발 때 총이 흔들림(대개 왼쪽 아래). 침착하면 없음.
- 총+탄 분산: 축별 표준편차 1.25 MOA(5발 군집 평균 3.9 MOA). 총열 과열(발당 +2.6 °C, 10분 시정수로 냉각): 수십 발 연속이면 분산이 커지고 탄착점이 조금 이동.
- 조준 진입 0.34 s.

### 탄도 (`src/physics`)
- 모든 탄은 실제 투사체: 중력 + G7 항력(BC 0.151) + 바람(공기 대비 상대속도) + 코리올리(북위 48°) + 스핀 드리프트(Litz 경험식) + 횡풍 공력 도약(Litz). ICAO 표준 대기.
- 1 ms 고정 서브스텝 RK4, 매 스텝 이전→현재 위치 선분으로 충돌 검사(빠른 탄이 얇은 물체를 건너뛰지 않음).
- 재질별 관통·편향(`src/data/materials.js`): 잎·덤불은 통과(미터당 손실 + 잔가지 타격 시 편향), 가는 줄기(약 10 cm 이하)는 관통하되 큰 감속·편향·텀블링, 굵은 줄기·통나무·흙둔덕·지면은 막힘(지면·둔덕은 얕은 각도면 도탄, 줄기 가장자리를 스치면 짧은 현만 뚫고 꺾여 나감), 인체는 연조직 관통 능력으로 계산(팔다리는 대개 관통 후 뒤의 몸통에 맞을 수 있음).
- 탄착 효과: 흙먼지 기둥(1~2 m, 수 초간 바람에 흘러감 — 300 m 밖에서도 4배율로 보임), 나무 껍질·생나무 파편과 흰 생채기, 잎 흩날림, 피격 시 옷 먼지(고어 없음), 총구 섬광·연기, 엎드려쏴 흙먼지, 탄피 배출·낙하음, 버린 탄창.

### 적 (`src/enemies`, `src/ai`, `src/data/anatomy.js`, `src/data/scenario.js`)
- 원기둥·상자 관절형 인체(키 1.75 m, 어깨폭 0.45 m), 탁한 절차적 위장 무늬(무광), 조끼·파우치·배낭·무릎 보호대·헬멧 커버 천 조각으로 윤곽이 깨지고 절반은 얼굴 위장. 표식·윤곽선 없음. 먼 숲 안의 적은 숲 그늘·대기 원근으로 어둡고 흐리다.
- 히트박스 20개: 머리, 목, 흉부 중앙(심장·대혈관), 좌우 폐, 척추, 복부, 골반, 위팔·아래팔·손, 허벅지·정강이·발.
- 부상 모델(체력바 없음): 머리·목·흉부 중앙·척추 → 힘이 빠지며 그 자리에 쓰러지고 총을 떨어뜨림 / 폐 → 2.5~7 s 안에 쓰러짐 / 복부·골반 → 즉시 주저앉고 엄폐물 쪽으로 기어감 / 다리 → 쓰러져 기어감 / 팔 → 총을 놓치거나(65%) 팔을 감싸고 엄폐물로. 맞는 순간 탄 방향으로 움찔, 쓰러지는 소리는 거리만큼 늦게.
- 반응: 근탄('딱'·근처 탄착)·동료 피격에 0.3~0.8 s 뒤 엎드리거나 위협 반대편 엄폐물 뒤로 웅크려 달려감. 탄보다 먼저는 반응하지 못한다 — 첫 발이 가장 중요하다. 그 뒤의 행동(내다보기·자리 옮기기·응사·기동)은 2단계 전술.
- 1단계의 시나리오(맞은편 8명·연결 숲띠 5명·들판 횡단자)는 2단계 시나리오로 바뀌었다.

### 소리 (`src/audio`, 1단계)
- 합성 총성: N파 충격 + 폭발 노이즈 + 몸통 울림 + 저음 충격 + 노리쇠 뭉치·완충 스프링 소리. 들판은 짧은 잔향 + **실제 숲띠까지 왕복 거리만큼 늦은 메아리**, 숲띠 안은 줄기 반사로 긴 잔향.
- **음속 지연(343 m/s)**: 탄착음·명중음·쓰러지는 소리·떨어진 총 소리가 거리/343 s 늦게 도착(300 m 명중이면 약 0.9 s). 거리 감쇠 + 공기 흡수(고음 감쇠) + 바람 방향 효과.
- 노리쇠·탄창·파우치 소리, 탄피가 흙·풀·길에 떨어지는 소리, 지면별 발소리 6종(+덤불 헤치는 소리, 장비 덜그럭), 숨 참기/내쉼/거친 호흡, 바람(세기·돌풍), 잎 스치는 소리, 풀벌레.

## 명중 검증 — 적 사수 (`npm run test:accuracy`)

## 3단계(무기·장비 확장)를 붙일 지점

- **새 무기(기관총·지정사수 소총)**: `src/data/weapons.js`에 항목(초속·강선·발사 속도·탄창·재장전·반동 자세표·흔들림·총열 과열), `src/data/ammo.js`에 탄(BC·질량·분산·관통 기준 속도). 탄도·영점·BDC·사거리표(`test:ballistics`)는 데이터에서 계산된다. 적은 지금 `ENEMY_WEAPON` 하나를 `Shooter` 모듈 맨 위에서 고정해 쓰므로, 병사별 무기는 `scenario.js`의 조/역할에 무기 id를 두고 `EnemyManager._spawn` → `new Shooter(e, ctx, skill, weaponId)`로 넘기면 된다(조준 앙각 표 `holdFor`도 무기별로).
- **양각대·거치**: `AimModel`에 이미 거치 배율이 있다(`rest`). 기관총 양각대는 엎드림 거치의 한 종류로, 연발 반동은 반동 자세표의 `residual`·`yawBias`로.
- **조준경 단 적(지정사수)**: `Senses.evaluate`의 겉보기 면적 Ω에 배율² — 병사별 `visionScale`이 이미 있다. 렌즈 반사(섬광)는 플레이어 쪽 가시도 계산에 대비 항으로.
- **수류탄·폭발**: 포물선·튕김·지연 신관은 `BulletSystem`과 별도 투사체로 두고, 폭발은 `'explosion'` 이벤트 → 파편은 `BulletSystem.fire`(파편 탄 데이터)로, 제압은 `SUPPRESSION`에 폭풍 항목, 소리는 `AudioEngine.propagate`(거리/343 s 지연), 적 청각은 `Senses`에 폭음 처리(총성과 같은 방위·거리 오차 구조).
- **방탄복·헬멧**: `anatomy.js` 히트박스에 판(덮는 부위·재질)을 두고, 판 재질을 `materials.js`에 넣어 `BulletSystem`의 관통 계산으로 남은 속도를 구한 뒤 `Enemy.onBulletHit`/`PlayerHealth.onHit`로 넘긴다(탄 정보 `info.bullet`·`exitSpeed`가 이미 전달된다).
- **고장(급탄 불량·불발)**: 플레이어는 `WeaponSystem._pullTrigger`와 재장전 타임라인(`Magazines`), 적은 `Shooter.tryFire`에 발당 고장 확률(무기 데이터)과 처치 동작 시간을 넣는다. 적이 고장 처치 중이면 `Squad.shout('reloading')`처럼 외칠 수 있다.
- **장비(지혈대 개수·탄창 수·무게)**: `PlayerHealth.toggleTourniquet`, `Magazines`(파우치 대기열), 이동 배수(`movement.js`).
- **적 무기 종류별 전술**: `Brain._fireIntent`(제압 점사 길이·간격)와 `Squad._command`(기관총이 기지 사격조를 맡도록).

## 알려진 문제

- 오른손잡이 기준이라 나무 줄기에 기대는 거치는 줄기를 왼쪽(받침손 쪽)에 둘 때 된다. 무릎·서서 거치는 받침 높이에 맞춰 몸을 낮춘다고 보고 받침이 손 아래 30·20 cm 안이면 인정한다(자세 높이가 세 단계뿐).
- 이 개발 환경에는 GPU가 없어(소프트웨어 렌더러) 실제 fps를 측정하지 못했다. `npm run shots`의 7개 시점, '높음' 1080p에서 그리기 호출 237~410회, 삼각형 176만~244만 개(그림자 패스 포함; 작업 전 137~226회, 79만~94만 개). CPU 갱신은 프레임당 0.7~1.5 ms(대부분 0.9 ms 안팎: 나무 LOD·식생 타일·떨어지는 잎·먼지·바람). GPU가 있는 곳에서는 디버그 모드 F8 화면의 fps나 `SHOTS_GPU=1 npm run shots`로 확인한다. 느리면 Esc → 그래픽 품질 '중간'/'낮음'(새로고침 후 적용).
- 첫 로딩에 수 초가 더 걸린다(나무 템플릿·껍질·잎 아틀라스 생성과 임포스터 굽기).
- 인물·총은 단순한 상자·원기둥 모양이다.
- 엎드리면 30발 탄창이 땅을 약간 파고든다(총구-지면 걸림은 처리하지만 탄창은 검사 안 함).
- 적이 쓰러질 때 시간 연출(래그돌 아님) — 지형 경사에서 몸 일부가 땅에 묻힐 수 있다.
- 적의 발이 방향 전환 시 약간 미끄러진다. 기어가기 애니메이션은 단순하다.
- 포인터 잠금이 풀리면(Esc, 창 전환) 자동 일시정지한다.
- (2단계) 이 지도에는 400 m 거리에서 실제로 하늘을 등지는 자리가 없다 — 스카이라인 탐지는 시험에서 배경만 바꿔 확인했다.
- (2단계) 총성 위치 짐작은 '그 방향의 숲띠 긴 변'에 맞춘다. 들판 한가운데에서 쏘면 적은 그 방향 숲 가장자리를 의심하고, 숲띠가 직각으로 만나는 모서리 근처에서는 어느 띠인지 헷갈릴 수 있다(한 번에 한 가설만 가진다).
- (2단계) 노출 비용은 숲띠 지도 위 2차원 시선으로 근사한다 — 둔덕·배수로 둑 뒤의 낮은 지형 엄폐는 길 찾기 비용에 반영되지 않는다(엄폐점 선택에는 반영).
- (2단계) 적 사이 간격·부상자 끌기·철수는 단순하다. 무력화된 플레이어를 확인하러 오는 행동, 수류탄, 기관총은 없다(3단계).
- (2단계) 측정은 CPU 갱신만이다(GPU 없음). 적 16명 교전 중 CPU 갱신 평균 0.8~2.5 ms이고, 길 찾기가 몰리는 순간 적 갱신이 한 프레임 5~8 ms까지 튈 수 있다.
- (2단계) HRTF 패너는 소리마다 하나씩 만든다(동시 56개 제한). 교전이 격하면 먼 탄착음부터 빠진다.
- (2단계) 플레이어 몸은 판정용으로만 있다(1인칭이라 그리지 않음) — 팔·총의 위치는 근사.
